
# Bitácora Espacial

Portal de noticias reales sobre exploración espacial desarrollado con React y Vite.

## Tecnologías

- React
- JavaScript
- Vite
- CSS moderno
- Spaceflight News API

## Instalación

1. Clonar el repositorio.
2. Instalar las dependencias:

   npm install

3. Crear un archivo `.env` en la raíz con:

   VITE_API_URL=https://api.spaceflightnewsapi.net/v4

4. Iniciar el servidor:

   npm run dev

## API

Las noticias se obtienen mediante Spaceflight News API.

Documentación: https://api.spaceflightnewsapi.net/v4/docs/
